# AutoSort — Smart Waste Segregation Robotic Arm

An intelligent waste segregation project that combines robotics, software, and machine learning to support automated waste sorting.

## Overview

AutoSort aims to identify and sort waste using a robotic manipulator arm. The project combines a web-based interface, a backend application, and a machine-learning component to bring the hardware and software together.

## Key Features

- **Robotic Arm:** Designed for waste pick-and-place operations.
- **Machine Learning:** Includes a waste-classification model for the sorting workflow.
- **Web Interface:** Provides a user interface for interacting with the system.
- **Backend Integration:** Connects application logic with the project's software components.
